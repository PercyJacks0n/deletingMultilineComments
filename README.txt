Назначение

Программа удаляет многострочные комментарии из кода на языке C,
учитывая обход по строковым и символьным константам, а также однострочным комментариям.

Входные данные

Входной текстовый файл с исходным кодом на C/C++.
Допустимые расширения: .c, .cpp, .h.
Максимальное количество строк: 1000.
Максимальная длина строки: 1000 символов.
В тексте программы запрещено использовать директивы #define дабы не пропустить многострочные комментарии скрывающиеся за счет директивы define

Выходные данные

Выходной текстовый файл с кодом, из которого удалены все многострочные
комментарии. При наличии ошибок выходной файл не создаётся.
